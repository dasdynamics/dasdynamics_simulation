## dasdynamics_simulation

Репозиторий содержит ROS 2-пакет с файлами запуска и конфигурационными файлами для симуляции робота в среде Gazebo.

***

## Требования и установка

Для работы пакета требуется установленный ROS 2. В данном случае используется дистрибутив **ROS 2 Lyrical**.

### Инструменты для симуляции

Для симуляции установите пакет `ros-gz`:

```bash
sudo apt install ros-lyrical-ros-gz
```

### Зависимости

Также необходимо иметь подготовленный пакет с описанием робота. Для тестирования можно использовать пакет `smartbox_description`:

```bash
git clone https://github.com/dasdynamics/smartbox_description.git
```

***

## Быстрый запуск

После сборки пакета для быстрого запуска используйте следующую команду:

```bash
ros2 launch dasdynamics_simulation simulation.launch.py
```

***

## Настройка параметров запуска

Основные параметры запуска можно изменить, отредактировав файл `simulation.launch.py`.

### Доступные для изменения параметры:

- `robot_name` — имя робота в симуляции
- `simulation_pkg_name` — название пакета симуляции (на случай изменения имени пакета)
- `description_pkg_name` — название пакета с описанием робота
- `gazebo_pkg_name` — название пакета Gazebo (для совместимости с устаревшими или новыми версиями)
- `gazebo_config_file_name` — название файла конфигурации Gazebo
- `gazebo_world_file_name` — название файла с описанием мира для симуляции
- `rviz2_config_file_name` — название файла конфигурации RViz2

> **Примечание:** Для редактирования откройте файл запуска `simulation.launch.py` в директории `launch` и измените параметры на соответствующие вашему проекту.

> Если функционала пакета будет недостаточно, вам потребуется изменить основную часть файла запуска или один из конфигурационных файлов в директории `config`.

***

## Структура репозитория

```
config/
    gz_bridge_config.yaml          — описание мостов между топиками Gazebo и ROS 2
    rviz2_simulation_config.rviz   — конфигурационный файл для запуска RViz2

launch/
    simulation.launch.py           — основной файл запуска пакета

worlds/
    dasdynamic_test_world.sdf      — описание мира для симуляции в Gazebo
```
